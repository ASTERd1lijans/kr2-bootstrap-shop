# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Проект представляет собой учебную версию интернет-магазина / автосалона **ast3rr Auto**, разработанную с использованием современного CSS-фреймворка **Bootstrap 5**.

Проект развивает предметную область контрольной работы №1 (каталог автомобилей премиального и массового сегментов) в отдельном репозитории `kr2-bootstrap-shop`.

## Практическая работа 9

Тема: «Bootstrap-сетка: `container`, `row`, `col-*` и базовая структура страницы».

Выполнена главная страница интернет-магазина на Bootstrap-сетке.
Реализовано:
- подключение Bootstrap 5 через CDN (CSS и JS Bundle);
- подключение собственного файла стилей `css/custom.css`;
- оформление шапки страницы (`header`) с синим фоном `bg-primary text-white` и бейджем КР №2;
- создание адаптивной навигационной панели (`navbar navbar-expand-lg navbar-dark bg-dark`);
- разработка hero-блока на 12-колоночной сетке (`container`, `row align-items-center g-4`, `col-12 col-lg-6`);
- создание блока преимуществ с адаптивными колонками (`row g-4`, `col-12 col-md-4`);
- создание сетки популярных товаров (`col-12 col-md-6 col-lg-4`);
- адаптивный подвал страницы (`footer` с сеткой `row`, `col-12 col-md-6`);
- применение utility-классов отступов (`my-5`, `mb-4`, `p-4`, `gap-2`), типографики (`display-5`, `lead`, `fw-bold`), границ и теней (`border`, `rounded`, `shadow-sm`).

## Практическая работа 10

Тема: «Bootstrap-компоненты: навигация, карточки, кнопки, формы, модальное окно, сообщения и значки».

Выполнено:
- добавлена единая Bootstrap-навигация (`navbar`) с выпадающим меню (`dropdown`) и активными состояниями пунктов на всех страницах;
- создана страница каталога товаров `catalog.html`;
- создана страница подробного описания товара `product.html`;
- создана страница оформления заявки `order.html`;
- использованы готовые компоненты Bootstrap:
  - `navbar` — адаптивная шапка с гамбургер-меню для мобильных устройств;
  - `card` — карточки товаров с `card-img-top`, `card-body`, `card-title`, `card-text`;
  - `btn`, `btn-primary`, `btn-outline-primary`, `btn-outline-secondary` — стилизованные кнопки действий;
  - `badge` — значки статусов товаров («Хит», «Эксклюзив», «Выгода», «Новинка», «В наличии»);
  - `alert` — информационные и предупреждающие сообщения с атрибутом `role="alert"`;
  - `modal` — интерактивные всплывающие модальные окна для быстрой заявки и подтверждения отправки;
  - `breadcrumb` — навигационная цепочка «хлебные крошки»;
  - `form-control`, `input-group`, `input-group-text`, `form-select`, `form-check` — адаптивная форма заявки;
  - `accordion` — интерактивный раскрывающийся список для секции частых вопросов (FAQ) и комплектации;
  - `table`, `table-striped`, `table-bordered`, `table-responsive` — адаптивная таблица технических характеристик;
- обновлён файл `css/custom.css` для минимальных доработок (кадрирование `card-img-top`, плавный hover для карточек, прижатие футера к низу экрана);
- проект полностью подготовлен к сдаче контрольной работы №2.

## Как проверить проект

1. Открыть `index.html` в браузере (или через локальный сервер `python3 -m http.server`).
2. Проверить навигационную панель `navbar`, переход между страницами и выпадающее меню «Дополнительно».
3. Открыть `catalog.html`, проверить отображение карточек `card`, значков `badge` и открытие модального окна `modal` при клике на «Заказать».
4. Открыть `product.html`, проверить хлебные крошки `breadcrumb`, адаптивную таблицу характеристик и работу раскрывающегося списка `accordion`.
5. Открыть `order.html`, проверить поля формы (`form-control`, `input-group` с `+7`, `form-select`, `form-check`) и открытие окна подтверждения отправки.
6. Открыть DevTools браузера (F12) и протестировать адаптивность на ширинах экранов:
   - 375px (смартфоны — колонки в 1 столбец, мобильное гамбургер-меню);
   - 768px (планшеты — перестроение в 2 колонки);
   - 1024px и 1440px (десктоп — 3 и 4 колонки, развернутый navbar).
