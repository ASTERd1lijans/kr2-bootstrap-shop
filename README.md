# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Проект представляет собой учебную версию интернет-магазина / автосалона **ast3rr Auto**, разработанную с использованием CSS-фреймворка **Bootstrap 5**.

Проект продолжает предметную область контрольной работы №1 (каталог автомобилей премиального и массового сегментов) в отдельном репозитории `kr2-bootstrap-shop`.

## Практическая работа 9

Тема: «Bootstrap-сетка: `container`, `row`, `col-*` и базовая структура страницы».

Выполнена главная страница на Bootstrap-сетке.
Реализовано:
- подключение Bootstrap через CDN (CSS и JS Bundle);
- подключение собственного файла `css/custom.css`;
- шапка страницы с названием автосалона и бейджем КР №2;
- адаптивная Bootstrap-навигация (`navbar navbar-expand-lg navbar-dark bg-dark`);
- hero-блок на 12-колоночной сетке (`container`, `row align-items-center g-4`, `col-12 col-lg-6`);
- блок преимуществ (`row g-4`, `col-12 col-md-4`, `h-100`, `shadow-sm`);
- сетка популярных товаров (`row g-4`, `col-12 col-md-6 col-lg-4`, `badge`, `btn`, `card`);
- подвал страницы (`footer` с сеткой колонок и ссылками).

## Используемые технологии

- HTML5 (семантическая разметка);
- Bootstrap 5.3.3 (12-колоночная сетка, utility-классы, компоненты);
- CSS3 (`css/custom.css` для кастомизации);
- Git, GitHub.
